issue 13 证据：登记类型的实测输出（= tests/kernel/test_format_derive.cpp 的期望串来源）

探针：build/derive_probe4.cpp（临时文件，不入库；源码见本文件末尾）
编译：g++ -std=c++17 -Wall -Wextra -Wpedantic -fno-exceptions -fno-rtti \
        -include config/embark_config.h -I include -I build/include \
        -I third_party/etl/include derive_probe4.cpp -o derive_probe4.exe
运行：./derive_probe4.exe        # 编译零警告；GCC 15.1 / MinGW-w64

--- 实测输出 ---------------------------------------------------------------
Error            |embark::Error::not_found|
BackgroundPolicy |embark::BackgroundPolicy::tick|
PixelFormat      |embark::hal::PixelFormat::rgb565|
InputEventKind   |embark::hal::InputEventKind::press|
Rect             |embark::hal::Rect { x = 0, y = 0, width = 320, height = 240 }|
DisplayInfo      |embark::hal::DisplayInfo { width = 320, height = 240, format = embark::hal::PixelFormat::rgb565, stride_bytes = 640 }|
InputEvent       |embark::hal::InputEvent { kind = embark::hal::InputEventKind::press, x = 160, y = 170, key = 113, timestamp_ms = 7 }|
AppSettings      |embark::AppSettings { background = embark::BackgroundPolicy::own_task, period_ms = 50, task_stack_words = 256, task_priority = 4 }|
CrossTaskMessage |embark::CrossTaskMessage { from_app = 1, seq = 7 }|

--- 说明 -------------------------------------------------------------------
- 枚举打的是带命名空间的**全名**（EFMT_DERIVE_SHOW_TYPE 默认 1）；结构体是
  `类型名 { 字段名 = 值, ... }`，字段名来自类型声明，加字段不用改调用点。
- 嵌套成员跟着类型自己的登记走：DisplayInfo.format 打成
  `embark::hal::PixelFormat::rgb565`。
- 1 字节整型字段（key / task_priority / from_app）能打出十进制数字，靠的是
  "字段类型抬到 uint16_t"这个规避动作 —— 副作用（原为 uint8_t 时被当字符打）
  见 upstream-1byte-bug.md。
- CrossTaskMessage 没有整体派生（有基类与构造函数），它的名字表来自类型体内的
  `E_FMT_FIELDS(from_app, seq);`。

--- 探针源码 ---------------------------------------------------------------
```cpp
#include <cstdio>

#include <embark/app.h>
#include <embark/error.h>
#include <embark/hal/types.h>
#include <embark/message.h>
#include <middleware/efmt/core/format.hpp>

template <typename T>
void show(const char* label, const T& value) {
  char buffer[192];
  e_fmt::format_to(buffer, sizeof(buffer), "{}", value);
  std::printf("%-16s |%s|\n", label, buffer);
}

int main() {
  show("Error", embark::Error::not_found);
  show("BackgroundPolicy", embark::BackgroundPolicy::tick);
  show("PixelFormat", embark::hal::PixelFormat::rgb565);
  show("InputEventKind", embark::hal::InputEventKind::press);
  show("Rect", embark::hal::Rect{0, 0, 320, 240});
  show("DisplayInfo", embark::hal::DisplayInfo{320, 240, embark::hal::PixelFormat::rgb565, 640});
  show("InputEvent", embark::hal::InputEvent{embark::hal::InputEventKind::press, 160, 170, 113, 7});
  show("AppSettings", embark::AppSettings{embark::BackgroundPolicy::own_task, 50, 256, 4});
  show("CrossTaskMessage", embark::CrossTaskMessage{embark::AppId{1}, 7});
  return 0;
}
```
