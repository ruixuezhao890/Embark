界面工程

换 .aid 只换「源文件」，导出目录永远是 app/aidogui_ui/export/（构建只认那里）。换完要点「重新导出屏」。

跑起来（模拟器）

窗口起来后直接用鼠标点它；右边预览每 0.5 秒跟着刷新。

让它生效

改 C++ → 构建；改界面 → 重新导出屏（会接着自动构建）。
